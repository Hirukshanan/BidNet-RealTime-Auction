# BidNet - Real-Time Distributed Auction System

## Project Description

BidNet is a university Network Programming project focused on real-time communication between multiple clients and a central Java server.

## Current Development Stage

The repository is currently at the foundation and setup stage. Auction functionality and networking have not yet been implemented.

## Core Technologies

- Java 21
- Maven
- TCP Socket Programming (future implementation)
- Jackson
- JUnit 5
- Git/GitHub

## Future Networking Focus

Later stages will explore:

- TCP socket communication
- Client-server architecture
- Concurrent clients
- Multithreading
- Synchronization
- Race-condition handling
- Real-time broadcasting
- Heartbeat and reconnection
- Fault handling
